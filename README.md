# IT Asset & Support Management System

A practical, lightweight Java application designed to manage workplace IT hardware inventory and track support tickets.

## Features
- **Asset Inventory Tracking:** Record hardware assets, categories, and availability status.
- **Support Ticket System:** Issue tickets tied to specific assets and track status (`OPEN`, `IN_PROGRESS`, `RESOLVED`).
- **File Persistence:** Automatically saves and loads assets and tickets to local text files (`assets.txt` and `tickets.txt`).
- **Interactive CLI:** Command-line menu interface for real-time asset and ticket management.

## Tech Stack
- **Language:** Java (JDK 17+)
- **IDE:** IntelliJ IDEA
- **Persistence:** Standard Java File I/O (`PrintWriter`, `Scanner`)
